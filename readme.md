# QA Testing with MySQL Data Verification

## Repository Overview

This QAT toolkit / repository contains three parts:

- **Part A:** This Readme file, containing the test case for an AI-generated web application.
- **Part B:** The AI prompt used to create the test web application, named `webapp-generation-prompt.txt`.
- **Part C:** The single-file PHP web application generated by AI, named `test-webapp.php`.

The full source of the test case is kept in the file `textcase.txt`.

## Test Case Documentation

| Field | Details |
|-------|---------|
| **Test Case ID** | TC-DataEntry-001 |
| **Test Case Title** | Data Entry - Valid |
| **Test Case Description** | Functional Testing of Data Entry page with Backend validation using MySQL queries. |
| **Preconditions** | Kara David Birthday Wishnote App is installed locally and MySQL database is pre-populated for comparison. Data entry page is accessed in latest Chrome/Firefox browser. |
| **Status** | Failed |

### Test Data

Five (5) valid entries containing First Name, Last Name, Government Position, and Location, each within the maximum character limits.

| Entry | First Name | Last Name | Government Position | Location |
|-------|------------|-----------|---------------------|----------|
| 1 | Juan | Dela Cruz | Mayor | Bacolod City |
| 2 | Maria | Santos | Governor | Iloilo |
| 3 | Pedro | Reyes | Senator | Manila |
| 4 | Ana | Garcia | Councilor | Cebu City |
| 5 | Jose | Ramos | Congressman | Davao |

### Test Execution

| Step | Action | Expected Result | Actual Result |
|------|--------|-----------------|---------------|
| a | Verify that the form contains labels in proper order and the text boxes are writable | The form contains labels in this order: "Target's First Name", "Target's Last Name", "Target's Government Position", and "Target's Location"; all text boxes are writable | The form contains labels in this order: "Target's First Name", "Target's Last Name", "Target's Government Position", and "Target's Location"; all text boxes are writable |
| b | Verify the "Send Wish Note" button | The "Send Wish Note" button changes color on hover and is not disabled | The "Send Wish Note" button changes color on hover and is not disabled |
| c | Enter test data on their respective fields | The respective fields accept data entries of valid test data | The respective fields accept data entries of valid test data |
| d | Click the "Send Wish Note" button, and a modal will appear | A modal titled "Verify Target Data" appears | A modal titled "Verify Target Data" appeared |
| e | Verify if the modal contains the same entry as the test data | The modal shows the same First Name, Last Name, Government Position, and Location that were entered | The modal showed the same First Name, Last Name, Government Position, and Location that were entered |
| f | Click the Cancel button | The modal closes and the form stays on the Data Entry page | The modal closed and the form stayed on the Data Entry page |
| g | Click "Send Wish Note" again, then click "Confirm and Send" in the modal box | The modal appears again and the form is submitted after clicking "Confirm & Send" | The modal appeared again and the form was submitted after clicking "Confirm & Send" |
| h | Verify if a successful entry message shows in the Data Entry page | The message "Success! The wish note has been sent." shows above the form | The message "Success! The wish note has been sent." showed above the form |
| i | Verify the test data in the database using `USE birthday_wishnote; SELECT * FROM main_corrupt_politicians;` | The database shows all five entries with FirstName, LastName, GovPosition, and Location saved | The database shows all five entries with FirstName, LastName, and GovPosition saved, but the Location column is NULL for all five rows |

## Findings

The test case **Failed** at step i. The web application reports a successful submission, but the Location value is not saved to the `main_corrupt_politicians` table. This matches the intentional flaw in the generated PHP script, where the INSERT statement omits the Location column.
